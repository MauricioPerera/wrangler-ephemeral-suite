Por qué existe

A veces necesitás más de una herramienta a la vez

Una reunión de trabajo suele necesitar charlar, dibujar algo en el momento, y pasar un archivo — no tiene sentido levantar tres cuentas temporales distintas con tres ventanas de expiración desincronizadas para eso.

🧩

Todo junto

Un único Worker, un único link base, tres herramientas bajo distintos prefijos de ruta.

🔀

Independientes igual

Cada herramienta también existe como repo standalone si solo necesitás una — la suite no las reemplaza.

🧹

Se limpia todo junto

Una sola cuenta temporal, un solo countdown — las tres desaparecen a la vez pasada la hora.

Cómo funciona

De cero a las tres herramientas en menos de un minuto

Cloná el repo

No hace falta tener cuenta de Cloudflare ni estar logueado.

git clone https://github.com/MauricioPerera/wrangler-ephemeral-suite.git cd wrangler-ephemeral-suite && npm install

Desplegá con --temporary

Wrangler crea una cuenta desechable, despliega el Worker con las tres herramientas, y te da la URL pública.

npx wrangler deploy --temporary

Elegí qué usar

La URL raíz te muestra un hub con links a /chat, /board y /drop. Compartí el que necesites.

¿Te gustó? Quedátelo

Wrangler también te da una claim URL. Abrila y logueate antes de que venza la hora y el Worker pasa a tu cuenta real, para siempre. Si no hacés nada, se borra solo.
